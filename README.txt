SignaLens Website

1. Extract ZIP.
2. Masukkan model Teachable Machine TensorFlow.js ke folder my_model/.
3. Masukkan gambar A.png sampai Z.png ke assets/signs/.
4. Masukkan tiga foto anggota ke assets/members/.
5. Buka folder di VS Code dan jalankan index.html menggunakan Live Server.
6. Klik Mulai Kamera dan izinkan akses kamera.

Struktur:
index.html
style.css
script.js
my_model/model.json
my_model/metadata.json
my_model/weights...
assets/signs/A.png - Z.png
assets/members/anggota-1.jpg - anggota-3.jpg
