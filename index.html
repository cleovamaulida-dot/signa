TENTANG KAMI

Belajar bahasa isyarat,
lebih dekat dan mudah.

Signa merupakan website berbasis pengenalan gambar yang dibuat untuk membantu pengguna mengenali alphabet bahasa isyarat melalui kamera. Website ini menggunakan model machine learning dari Teachable Machine untuk melakukan klasifikasi secara real-time.

01

Tujuan

Membuat proses pengenalan alphabet bahasa isyarat menjadi lebih interaktif, sederhana, dan mudah digunakan oleh siswa.

02

Teknologi

Website menggunakan HTML, CSS, JavaScript, TensorFlow.js, dan Teachable Machine Image Model.
